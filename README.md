## 🚀 Installation Guide
1. Go to the **Releases** section of this repository and download `Sakura_Audio_Boost_Final.zip`.
2. Launch the **Magisk App** on your phone.
3. Navigate to the **Modules** tab at the bottom right.
4. Tap **Install from storage** and select the downloaded ZIP file.
5. Wait for the terminal log to show success, then tap **Reboot**.
